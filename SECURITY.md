# Security Policy

## Reporting

Do not disclose vulnerabilities through public issues, discussions, or pull requests.

Report suspected vulnerabilities to `security@tolanicorp.us` and include:

- affected contract, service, repository, network, and address;
- reproduction steps or transaction evidence;
- impact assessment;
- whether funds, keys, governance, merchants, or users are at immediate risk;
- a secure method for follow-up communication.

## Repository status

This repository is documentation-only. Executable source retained in its history or default branch is deprecated and is not authorized for deployment.

The future canonical engineering repository is `Tolani-Corp/tolani-protocol`. Until its migration is approved, currently deployed DAO contracts remain controlled through `Tolani-Corp/TolaniEcosystemDAO`.

## No audit representation

Source verification on a block explorer is not a security audit. No repository statement should imply professional audit coverage unless a named audit report, scope, commit, findings disposition, and report digest are published.

## Emergency response

Potential loss-of-funds, key-compromise, unauthorized-upgrade, bridge, payment, treasury, or governance incidents should be treated as critical and escalated immediately to the Safe signers and protocol security operators.
